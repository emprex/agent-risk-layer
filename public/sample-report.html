Example static observation

ARL-MCP-001: MCP configuration exposes shell execution

critical

Observed: a command-capable MCP server is configured through mutable provenance. Evidence contains the rule result, path hash and bounded location data—not source code or command secrets.

Required action: remove general shell access or isolate it behind a hardened sandbox, immutable package pin, deterministic allowlist and transaction-bound approval.
