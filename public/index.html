What we look at

The five things that decide whether an agent is dangerous.

Access

What can it reach?

Accounts, systems, files, customer information and connected tools.

Data

What can it see?

Personal, confidential, financial, health or authentication information.

Actions

What can it change?

Messages, records, money, permissions, code and irreversible operations.

Approval

Who must agree?

Whether a person approves the exact high-impact action before execution.

Recovery

Can you stop it?

Emergency shutdown, credential revocation, logs, alerts and incident ownership.

Clear limits

Useful evidence without pretending it is a certification.

  • Assessments are private unless you enable sharing.

Common questions

Start without learning security jargon.

Do I need to be a security expert?

No. The check uses ordinary questions and explains why each answer matters. Technical evidence is optional at the beginning and clearly marked as unverified until it is tested or reviewed.

Will AgentRiskLayer see my source code or prompts?

The questionnaire does not require source code. The local Inspector is designed to produce redacted evidence without uploading source contents or matched secret values. Hosted runtime checks store decisions and bounded metadata rather than raw prompts, outputs or tool arguments.

Does a low score mean my agent is secure?

No. A result supports a decision within the stated scope. Unknowns, inaccurate answers and untested production behaviour remain limitations.

What should I do first?

Start with the free security check. It will tell you whether to proceed, gather evidence or fix material risks before connecting the agent to real systems.
