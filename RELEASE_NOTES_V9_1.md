# AgentRiskLayer v9.1.0 — Professional public access release

## Delivered
- Public self-service registration with no invitation system in the application path.
- Professional sign-in and account-creation experience with automatic CSRF recovery.
- Guided first-run dashboard and safer post-registration destination.
- Outcome-led homepage, concrete refund-control demonstration and inspectable product evidence.
- Company and live Status pages, consistent footer trust links and public production stage.
- Sanitised public readiness output that does not disclose database name, user, hostname or server version.
- Legacy invitation database tables are retained only for schema compatibility; invitation routes and runtime logic are retired.

## Boundaries
- Internal automated validation is not independent certification.
- External penetration testing, production history and formal compliance certifications remain separate work.
- Owner-controlled credentials are required to push and deploy the release.
