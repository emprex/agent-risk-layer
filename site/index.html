ARL Guardian · Public Preview

Map the authority surface before the assessment.

Guardian is a local, read-only capability discovery tool for AI-agent repositories. It maps reviewable evidence for MCP, outbound network access, filesystem mutation, process execution, credential references and approval boundaries without running the agent.

Guardian discovers. AgentRiskLayer assesses. Guardian does not decide severity, readiness, finding closure or deployment.

What we assess

Security around real agent authority.

Access & permissions

Repositories, data stores, credentials, tools and privilege boundaries.

Instruction attacks

Prompt injection, untrusted content, tool-result poisoning and instruction hierarchy.

Actions & approvals

High-impact actions, exact approvals, transaction boundaries and constrained targets.

Evidence & recovery

Auditability, containment, remediation evidence and exact retesting.

How it works

One bounded assessment workflow.

  1. 01
    Request & scope

    We understand the system, lifecycle stage and authorised test boundary.

  2. 02
    Freeze & inspect

    We bind evidence to the exact target revision and inspect the authority surface.

  3. 03
    Test & remediate

    Controlled tests run only with explicit authorisation. Findings stay evidence-backed.

  4. 04
    Retest & report

    The affected control is retested against the changed revision and reviewed by a human.

Decision boundary

The LLM is not the security authority.

AI can assist with explanation, organisation and drafting. It does not decide applicability, evidence validity, severity, finding closure, readiness or deployment.

Safe output ≠ safe action. A bounded PASS is not a universal security claim.
